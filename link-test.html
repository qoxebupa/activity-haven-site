Link tester

Paste an image or design link exactly as you would in the Hub's Image column. This page shows how the website will display it. Nothing is saved, and the Hub is not changed.

How it will look on the site

  • Canva: Share → More → Embed → copy the Smart embed link. Later edits in Canva show on the site automatically. Edit the same design; don't make a copy.
  • Google Drawings: File → Share → Publish to web → Image → Publish, and copy that link. Tick "Automatically republish when changes are made".
  • Google Slides: share as "Anyone with the link can view", open the slide you want, and copy the address from the browser bar.
  • A design shows tall (letter size) unless the link ends with #landscape or #square.
  • Changes can take up to about 5 minutes to appear. Reload this page to check.
